# FurnitureERP

## Spuštění aplikace

### Požadavky

- [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)

### Kroky

1. Obnovte závislosti:
   ```bash
   dotnet restore
   ```

2. Spusťte aplikaci:
   ```bash
   dotnet run --project FurnitureERP
   ```

3. Otevřete prohlížeč na adrese `https://localhost:7188`

4. Přihlaste se pomocí výchozích přihlašovacích údajů:
   - **Uživatel:** `admin`
   - **Heslo:** `Admin@1234`
